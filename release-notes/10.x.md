# 10.0.0

See https://github.com/spring-projects/spring-boot/wiki/Spring-Boot-4.0-Migration-Guide for the migration guide.

## Jackson kotlin module removal

~~Spring Boot has moved to Jackson 3, so there is no need to include com.fasterxml.jackson.module:jackson-module-kotlin
any more.~~

Although Spring Boot 4.0.0 has moved to Jackson 3, Spring Docs (and especially Swagger) still use Jackson 2. See the
[Spring Docs issue](https://github.com/springdoc/springdoc-openapi/issues/3169) for more details. This therefore means
that it is still worth including the jackson kotlin module in this plugin. We also now include the jackson 3 version of
the module.
