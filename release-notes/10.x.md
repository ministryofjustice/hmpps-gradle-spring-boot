# 10.0.6

## Pin swagger-ui to latest version 5.32.1
[CVE-2026-0540](https://nvd.nist.gov/vuln/detail/CVE-2026-0540)
[CVE-2025-15599](https://nvd.nist.gov/vuln/detail/CVE-2025-15599)

From the CVEs:
> medium severity - CVE-2026-0540 Improper Neutralization of Input During Web Page Generation ('Cross-site Scripting') vulnerability in pkg:javascript/DOMPurify@3.2.6
> CVE-2026-0540 - DOMPurify 3.1.3 through 3.3.1 and 2.5.3 through 2.5.8, fixed in commit 729097f, contain a cross-site scripting vulnerability that allows attackers to bypass attribute sanitization by exploiting five missing rawtext elements (noscript, xmp, noembed, noframes, iframe) in the SAFE_FOR_XML regex. Attackers can include payloads like in attribute values to execute JavaScript when sanitized output is placed inside these unprotected rawtext contexts.

and also:
> medium severity - CVE-2025-15599 Improper Neutralization of Input During Web Page Generation ('Cross-site Scripting') vulnerability in pkg:javascript/DOMPurify@3.2.6
> CVE-2025-15599 - DOMPurify 3.1.3 through 3.2.6 and 2.5.3 through 2.5.8 contain a cross-site scripting vulnerability that allows attackers to bypass attribute sanitization by exploiting missing textarea rawtext element validation in the SAFE_FOR_XML regex. Attackers can include closing rawtext tags like </textarea> in attribute values to break out of rawtext contexts and execute JavaScript when sanitized output is placed inside rawtext elements. The 3.x branch was fixed in 3.2.7; the 2.x branch was never patched.

Note that this change causes a problem in projects protected by spring security as by default the 5.32.0 version files are unprotected. To work around that issue set:
```yaml
springdoc.swagger-ui.version: 5.32.1
```
in your `application.yml`.

# 10.0.0

Upgrade to spring-boot [4.0.1](https://github.com/spring-projects/spring-boot/releases/tag/v4.0.1)

- If your project uses **Flyway**, you must add the Spring Boot Flyway starter dependency.
  Without it, Flyway migrations will **not run at application startup**.
- Add the following dependency:

```gradle
implementation("org.springframework.boot:spring-boot-starter-flyway")
```
See https://github.com/spring-projects/spring-boot/wiki/Spring-Boot-4.0-Migration-Guide for the migration guide.

## Jackson kotlin module removal

~~Spring Boot has moved to Jackson 3, so there is no need to include com.fasterxml.jackson.module:jackson-module-kotlin
any more.~~

Although Spring Boot 4.0.0 has moved to Jackson 3, Spring Docs (and especially Swagger) still use Jackson 2. See the
[Spring Docs issue](https://github.com/springdoc/springdoc-openapi/issues/3169) for more details. This therefore means
that it is still worth including the jackson kotlin module in this plugin. We also now include the jackson 3 version of
the module.
