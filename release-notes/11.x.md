# 11.0.0

## Upgrade to Spring Boot 4.1.0

Upgrade to spring-boot [4.1.0](https://github.com/spring-projects/spring-boot/releases/tag/v4.1.0).

We have classified this as a major upgrade because there are potentially breaking changes to the WebClient.Builder
filter functions introduced in the release (via spring security upgrade).

Due to https://github.com/spring-projects/spring-security/issues/19324
`ServletOAuth2AuthorizedClientExchangeFilterFunction` no longer works as expected in a servlet environment when there is
no request / response in context (e.g. when called from batch jobs). This means that all of those webclient requests
fail with a `401` as oauth2 authentication is not performed first.

If you are using kotlin lib to build your web clients then this upgrade will work without any further changes as a
temporary filter fix will be included in a matching release of that project.

It is worth searching your projects for `ServletOAuth2AuthorizedClientExchangeFilterFunction` usage. If you find any
usages then you will need to add in:

```kotlin
  .filter(ServletRequestResponseNonNullFilterFunction())
```

before the call to the oauth2 filter function.

Note that reactive applications are not affected by the issue and will continue to work as expected without any changes,
since it is only the servlet version of the filter function that includes the null code change.
